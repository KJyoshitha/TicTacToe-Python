# Tic Tac Toe

## Description
A two-player tic tac toe game in python with MySQL connectivity for storing player data.

## How To Play
Each player is alloted a symbol 'X' or an 'O'. The two players then take turns to play and win the game. 

Players can check the leaderboard to see who topped the list.

## PIP Install
For this game to run, the Python MySQL connector must be pip installed.

```
pip install mysql-connector-python
```
